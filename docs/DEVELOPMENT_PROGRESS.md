最後更新：2026-09-09

## 開發原則與完成定義

每項功能只有同時符合下列條件才能標記完成：

1. 對應內容規格中的章節。
2. 可在 Godot 遊戲中實際操作。
3. 有保存／載入策略（若會改變玩家狀態）。
4. 通過 headless 解析與核心測試。
5. 若為主視覺，使用生成資產，不以 Godot 預設面板代替。
