# 神祉角色設定：阿斯特萊雅（Astraea）

## 固定描述錨點

中性、永恆而帶有人性的宇宙引導神祉；蒼白暖灰膚色、微微發亮的琥珀金瞳、深靛至紫羅蘭漸層的及肩波浪髮，額前有一枚細小的青綠星晶；修長、安靜的面容帶有克制的憂鬱。穿深靛色無袖長袍，外層為半透明星雲薄紗斗篷，古銅金星儀肩飾與環狀項鍊，胸前有一顆青綠靈光核心。比例為優雅的 7.5 頭身，手持小型古銅星盤；畫面維持手繪宇宙奇幻插畫、靛藍／紫羅蘭／古銅金／青綠靈光配色，不出現文字、字母、數字或標誌。

## 個性與表演

- 平時：平靜、專注，像在傾聽靈魂。
- 鼓勵：嘴角極淡的微笑，星晶短暫變亮。
- 罕見掉落：抬起星盤，斗篷星塵向外擴散。

## 外觀槽

- 頭飾：星晶、月冠、虛空面紗。
- 斗篷：初始星雲、金誓長披、日蝕羽衣。
- 星盤：原始星盤、稜鏡星盤、冠冕星盤。

## 預言短句

- 「每一道偏移，都曾是某人的選擇。」
- 「別急，星塵記得你的手勢。」
- 「你沒有失去靈魂；你只是送它回家。」
