# AFTERLIFE INC. 內容規格 v1.0

> 本文件是目前原型的唯一內容基準。任何新增機制、數值、畫面或資產都必須先能對應到本文件的章節；未決內容要標為「待決」，不能假裝已完成。

## 1. 遊戲定位

**名稱：** AFTERLIFE INC.／死後管理局  
**類型：** 美術驅動的宇宙奇幻增量遊戲，帶有短局專注互動。  
**平台：** Windows / Steam，買斷制；成熟後以內容型 DLC 擴充。  
**視覺原則：** 深靛、紫羅蘭、青綠靈光、古銅金星儀。主畫面、卡牌、星圖、結算皆由生成插畫作為視覺本體；Godot 只負責透明互動區、數字、動畫與必要詳細文字。

玩家的感受順序是：好奇「這是什麼儀器」→ 親自引導第一顆靈魂 → 收集命運牌與靈魂 → 打開龐大的宇宙星圖。

## 2. 核心循環

### 2.1 初次輪迴前

1. 三張生成牌背中選一張。
2. 選中的牌實際翻轉成卡面。
3. 顯示該牌的名稱與本局規則；玩家確認。
4. 靈魂光球穿越導向閘門並掉入彈珠路徑。
5. 顯示結算：牌面、進入閘門、精準度、倍率、業力與碎片。
6. 獲得業力，逐步解鎖星圖與重生門檻。

### 2.2 首次重生後

1. 翻牌並確認本局規則。
2. **命運校準**：依序鎖定浮文。初始 3 枚，最終上限 8 枚。
3. 每次鎖定只控制一枚浮文；浮文沿圓形、八字或星形軌跡運動。
4. 已鎖浮文改變半透明落點預測線與彈珠方向。
5. 所有浮文完成後，靈魂掉落。
6. 依掉落閘門、碰撞、牌面規則與節印精準度結算。

**單局目標時長：** 20–35 秒。失誤仍保底給少量業力；手動局的高精準回報應高於自動處理。

## 3. 資源與經濟

| 資源 | 取得 | 使用 | 原則 |
| --- | --- | --- | --- |
| 業力 Karma | 基礎掉落、部門處理、離線收益 | 業力星圖、部門、基礎卡 | 不可直接兌換其他主資源 |
| 靈魂碎片 | 稀有靈魂、碎片閘門、特定卡 | 靈魂支線、背包、稀有卡 | 不可直接兌換業力以外的主資源 |
| 命運印記 | 重生 | 宇宙星圖、新規則、初始增益 | 永久、稀有 |
| 榮譽 | 每週排名與挑戰 | 稱號、外觀、小幅便利 | 不影響每週公平排名 |

特殊商店可販售「組合遺物」，但只能消耗多種資源共同購買，不能把資源互相轉換。

## 4. 命運牌收藏

### 4.1 卡牌規則

- 卡牌是永久收藏；起始收藏 10 張，版本 1.0 目標至少 30 張，長期擴充至 100 張。
- 每局從已持有卡中隨機抽出 3 選 1。
- 卡面無文字，翻開後才顯示短規則文字。
- 限定卡屬於一次性強力消耗品，從特殊商店或週活動取得。

## 5. 靈魂、背包與圖鑑

- 靈魂外觀：人形剪影包在不同稀有度光球中。
- 稀有度：平凡、罕見、稀有、史詩、傳說。
- 性質：記憶、星辰、混沌、慈悲、虛空等。
- 首次取得即解鎖圖鑑條目與短敘述，不設額外等待研究遊戲。
- 高稀有靈魂可存入小型背包；初始 3 格，須以碎片／星圖解鎖更多格。
- 滿格時玩家可手動釋放換少量業力，或後期解鎖自動處理。

## 6. 技能星圖

星圖必須是可探索的生成插畫，節點以圖示與光效呈現，**不可把技能名稱鋪在星圖上**。只有點擊節點才顯示星空外框、名稱、效果、成本與前置條件。

| 分支 | 主題 | 代表效果 |
| --- | --- | --- |
| 業力星圖 | 校準、連擊、部門效率 | 容錯、業力倍率、處理速度 |
| 靈魂星圖 | 掉落、背包、稀有靈魂 | 碎片率、庫存、靈魂特性 |
| 宇宙星圖 | 重生後開放 | 新軌跡、新互動、規則改寫 |

目前原型先提供 5 個可點擊示範節點；正式版需 36+ 節點與互鎖路徑。

## 7. 神祉與長期目標

- 神祉為固定幾種原型角色：中性神秘、優雅女性、冷峻男性。
- 玩家以外觀物品裝扮神祉，並逐步解鎖短句預言。
- 短期目標：首次重生。
- 中期目標：開啟宇宙星圖並收集命運牌。
- 長期目標：完成終極輪迴、解鎖每週特殊規則與榮譽外觀。

## 8. 商店、排行與 Steam

- 特殊商店固定基礎商品並每 20 分鐘輪替稀有卡／限定遺物。
- Steam Cloud 用於存檔同步。
- Steam Leaderboard 用於單局最高命運印記與每週特殊規則；它不是通用資料庫。
- 週榜獎勵以榮譽、稱號、外觀為主，不提供會影響公平排名的資源優勢。

## 10. 不在 v1.0 核心範圍

- 多人即時互動。
- 自建後端資料庫。
- 把未完成內容切割為付費 DLC。
- 以大量文字取代主要視覺。
